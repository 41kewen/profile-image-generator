# 个人名片图片生成器

本地生成四板块毛玻璃 **PNG 图片**。浏览器只是编辑器，导出的是图片，不是网页或页面截图。

![生成效果](docs/example.png)

## 在线使用

打开 [在线生成器](https://41kewen.github.io/profile-image-generator/)，无需下载或安装即可编辑并导出 PNG。图片和配置在当前浏览器处理，不上传到 GitHub；在线地图和地点搜索仍会请求第三方地图服务。

GitHub Pages 由 `.github/workflows/pages.yml` 在 `main` 分支更新后自动构建部署，仅发布网页和许可文件，不发布 Windows 启动脚本。

## 下载使用

在 [Releases](https://github.com/41kewen/profile-image-generator/releases) 下载最新版 ZIP，完整解压后双击 `start-generator.cmd`。

Windows 10/11 自带 PowerShell 加上较新的 Chrome/Edge 即可使用，不需要 Node.js、Python、账号或 API Key。

1. 编辑个人简介：名字、头像、顶部封面、简介区域背景、标签、个性签名与社交标识。
2. 选择地图位置：城市、地点搜索、经纬度、点击选点、拖动平移、缩放；也可上传地图截图。
3. 编辑项目 / 兴趣卡片的文字、图标、色调和背景。
4. 调整全景背景、取景位置、压暗与玻璃质感，点击「导出 PNG」。

上传图片会先打开手动取景窗口，原图完整显示，拖动选区和调整放大范围后确认。不会直接套用居中裁剪；取消不改变当前图片。头像、封面、全景背景、卡片背景、图标和地图截图均支持这一流程。

导出尺寸为 1376 × 928、2752 × 1856、4128 × 2784；不包含编辑按钮。配置可保存为包含图片与当前地图快照的 JSON，后续可离线导入。名字和超过版面容量的文字会缩小或省略；标签最多显示两行。

## 地图和离线模式

地图使用真实 OpenStreetMap 数据，而不是只替换地名文字。杭州是通用示例位置，不代表任何人的真实地址。

- 默认示例地图、上传地图图片和已保存地图快照可离线生成。
- 新位置和地点搜索需要网络。
- 在线选点请使用在线生成器，或通过启动器进入真正的本机 HTTP 编辑器。直接打开 HTML 仅支持内嵌地图、快照和截图；不会伪造来源头绕过地图服务政策。
- 地图加载失败时暂停导出，避免生成坐标与地图不匹配的图片。
- WGS84 经纬度，纬度范围 ±85.051128°，经度范围 ±180°。
- 设备位置需要浏览器和操作系统许可；不可用时可以输入坐标。
- 地图署名不可删除；上传第三方地图截图时也应按其许可填写来源。

## 隐私与默认素材

头像、照片、文字和配置只在本机浏览器处理。地图加载会向 OpenStreetMap 请求位置附近的瓦片，地点搜索会向 Nominatim 发送查询词。

本机服务只绑定 `127.0.0.1:19168`，只提供生成器，不开放目录或局域网。`stop-generator.cmd` 可停止服务；无请求两小时自动退出。服务退出后重新双击启动器即可。

默认内容是通用示例；头像、封面、风景和小卡片图标为原创矢量装饰图，均可替换。仓库不包含用户参考截图、参考头像、旧主页个人资料、本机配置、测试记录或凭据。

## 源码开发

需要 Node.js 20.19+，开发依赖用 npm 管理。

```sh
npm ci
npm run build
npm start
```

打开终端提示的本机地址。构建产物在 `dist/`，也可指定目录：

```sh
node build.mjs path/to/output
```

代码运行和构建不依赖第三方 UI 框架。`npm ci` 安装的 Playwright 与 sharp 仅服务于开发测试。

### 测试

```sh
npx playwright install chromium
npm test
```

默认测试使用固定瓦片和地点响应，不向公共地图服务自动发送请求。覆盖真实 PNG 导出、图片上传、配置像素一致性、位置交互、异常处理、移动端与个人信息清理。

显式检查真实在线地图：

```sh
npm run test:online
```

网络检查受第三方服务可用性影响。`PLAYWRIGHT_CHROMIUM_EXECUTABLE` 可指定本机 Chrome/Chromium 的完整路径；`GENERATOR_TEST_OUTPUT` 可指定测试的构建目录。测试记录写入 Git 忽略的 `validation/`。

### 目录

```text
src/              编辑器、渲染器、Windows 启动服务
assets/           原创装饰素材与带许可的默认地图
scripts/          单个示例地图的维护工具
tests/            功能与清理检查
docs/             通用示例成图
build.mjs         内嵌素材、样式与脚本，生成可分发工具
server.mjs        开发用跨平台本机服务
dist/             构建产物，不提交
validation/       本机验证记录，不提交
```

默认地图已包含在仓库中，正常构建不会联网。只有维护默认地图时，才需要手动运行 `node scripts/prepare-map.mjs`；它只读取一个可见范围，不预取城市或缩放级别。
